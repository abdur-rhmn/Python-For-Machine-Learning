# Python for Machine Learning — Practice Notebooks

A structured, hands-on practice repository built during a 4-week "Python for
Machine Learning" course comprising 17 modules, combining conceptual lessons
with applied practice each week.

## Overview
This repository documents a progressive learning journey — starting from
core Python programming fundamentals and advancing into applied data
analysis and visualization using industry-standard libraries. Each week
built on the previous one, culminating in a capstone exercise that combined
the full range of concepts covered throughout the course.

## Structure
- `week-1/` to `week-4/` — Weekly modules and practice notebooks
- `final-exam-employee-analysis/` — Capstone project applying the complete
  skill set on a real-world-style employee dataset

## Tech Stack
Python · NumPy · Pandas · Matplotlib · Seaborn · Plotly

## Note
This repository reflects a personal learning journey completed as part of a
structured course, rather than a single unified application.
