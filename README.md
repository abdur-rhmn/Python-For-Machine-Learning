# 🔢 Week 03 — Numerical Computing & Data Manipulation

### Focus

Developing the numerical and data-processing foundation required for Data Science and Machine Learning workflows.

## NumPy

Worked with NumPy's multidimensional array system and numerical operations.

### Key Capabilities

* Creating and working with `ndarray`
* Generating arrays with:

  * `arange()`
  * `linspace()`
  * Random data generation
* Working with 2D arrays
* Matrix construction
* Identity and diagonal matrices
* Advanced array slicing
* Broadcasting
* Understanding views vs copies

### Why It Matters

NumPy provides the numerical foundation behind many Python-based data science and Machine Learning workflows.
